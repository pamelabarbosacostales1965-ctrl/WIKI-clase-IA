# Maintain the wiki

[Home](README.md)

When adding future lectures:

1. Record the original filename, date if available, page/slide count, and checksum in the inventory.
2. Add a chapter with a local contents list, plain-English explanations, examples, and exact source locators.
3. Distinguish source content from study supplements. Mark unresolved ambiguities instead of inventing missing lecture details.
4. Add the chapter to README, comparisons, formulas, and practice questions where relevant.
5. Recheck Markdown links, formulas, units, example arithmetic, and algorithm assumptions.

Next source-dependent additions are probability/Bayes, naive Bayes, Markov models, dedicated planning, and ethics/safety. Add them when those class materials become available.

Keep synced class reference files unchanged. Work from private copies when correcting course code. Do not add a blanket license covering instructor slides or published readings without a supplied redistribution permission.
